## 不能通过代码补造的内容

- **过去未采集的字数、作者及精确时间**：历史快照中缺失的信息不代表零，也不能用今天的页面值冒充过去的观测。当前本机 09-08 起点四榜仍缺字数：畅销榜 114/420、签约新书榜 297/297、新人签约榜 326/327、三江榜 13/17；三江缺作者 13 本。后续采集会记录新的实际观察时间。页面和导出保留缺失说明。
- **第三方授权与作品内容权利**：软件修改不能代替上游作者授权，也不能授予小说简介、封面或商标的权利。来源与替代范围见[来源核对](来源核对.md)和[第三方声明](../THIRD_PARTY_NOTICES.md)。源码包只含合成示例，不分发真实采集数据。
- **验证码和站点变化**：不能保证平台随时可访问、字段完整或长期保持相同结构。遇到拦截时保留进度并遵守冷却；不通过删除状态、伪造指标或无限重试掩盖失败。

## 已隔离但没有改写的旧历史

原工作区的 Git 历史含 `.claude/settings.local.json`、`.claude/scheduled_tasks.lock` 和替代前实现。删除当前文件或修改忽略规则不会改变旧提交。本轮保留原历史以免破坏现有工作；首次开源使用 `scripts/build_source_release.py` 生成的源码包，在干净目录建立新仓库，不复制旧 `.git`。原历史检查仍应报告问题，不能为让它通过而关闭规则。

这不属于“源码无法开源”，而是旧历史没有完成相同的发布处理。需要保留旧历史公开时，仍须单独处理其中的私有记录和第三方授权。

## 需要外部环境验证的事项

- 全量实时爬取、真实 AI 返回质量和费用，需要在实际配置下运行；离线测试不能替代这些验证。
- 09-09 本机受限环境出现 `ERR_NETWORK_ACCESS_DENIED`，当次三个空快照未通过完整性检查，九份 latest 仍使用 09-08 数据。已修复起点和番茄对此错误的逐分类/逐榜重试。同一浏览器访问公共测试页时，受限环境报网络访问被拒，获准在沙箱外运行后返回 HTTP 200，确认当前沙箱存在网络限制。冷却到期后，获准联网的起点检查成功解析一页榜单 20 本（HTTP 202），首本详情字数、作者和简介齐全（HTTP 200）。这只验证了少量页面；全量、多平台和长期采集仍未重新验收。恢复步骤见[采集与数据质量](采集与数据质量.md#网络被拒后的恢复顺序windows)。
- Linux、Python 3.10 和 GitHub Actions 运行结果，以公开仓库首次 CI 为准；本机验证环境为 Windows、Python 3.12。
- Windows 注销后执行需要对应账户凭据、权限和网络条件；已登录后台测试不能替代注销环境验收。
- Excel 导出依赖外部 SheetJS CDN，封面依赖上游图片。网络不可用时使用 JSON/CSV；部署端响应头、仓库分支保护和私密漏洞报告等设置需在目标平台确认。
- 敏感信息扫描覆盖常见格式及本机已配置密钥的精确匹配，不能证明所有自定义凭据、图片或历史外部附件都不存在敏感信息。

| 原范围 | 当前实现 |
| --- | --- |
| scrapers/qidian.py 中列表提取 JS、详情/三江 JS | 删除这些提取脚本，新增 qidian_html.py，以 Python 标准库 HTMLParser 解析渲染后的 HTML 树；书籍 ID 来自合法的平台书籍链接，类别来自类别链接，字数要求明确“字”单位。 |

新解析器以合成 HTML 和实际网站响应验证，与旧 JS 使用不同的输入处理结构。既有缓存、进度恢复、请求预算、冷却、快照 schema 保留。本记录说明实际替代过程，不声称这是未接触旧代码的“净室”开发。

## 晋江 HTTP 层

核对来源：[JJClawler-full](https://github.com/lien-Gu/JJClawler-full)，提交 `9baccf912e60d133479780e9e5e42e7ebf41987e`。上游 README 声明 MIT，但未取得对应的 LICENSE 正文；因此没有自行补造一份“上游 LICENSE”。

上游 http_client.py 是 httpx/tenacity/asyncio 与独立熔断器组合，本项目旧代码是 urllib 同步实现，直接共通部分主要为浏览器式 Header 及端点使用参考。为消除既有引用实现的不确定性，本次仍替换请求与解析边界：

- 新增 JsonHttpClient，最小请求头使用 NovelIndex/1.0，不再复制 Chrome Header/Origin/Referer。
- 独立实现有界响应读取、压缩后大小限制、有限网络重试及 Retry-After 冷却；403/429/503 立即停止本次请求，冷却期间不再发起请求。
- 月榜响应按平台 rank_group_type、channelName、list 等字段解析，跳过畸形项；积分使用本项目公共数值解析器。
- 不引用上游的客户端、熔断器、配置或依赖。保留网站 URL/响应字段和原有本项目的跨分类缓存、状态文件、统一输出约定。

端点和字段是实际接口协议信息，不在本项目第三方许可记录中伪装为上游作者对代码的授权。历史参考继续致谢。

## 验证与发布边界

起点替代解析器少量实测：榜单 20 本、详情字数/作者/简介齐全、三江 17 本；晋江最小请求头返回月榜 20 本；番茄原生 Chrome 会话 HTTP 200，首屏 10 个书籍链接（首次请求超时，第二次成功）。这些是当次可用性检查，不保证站点长期可用。

tests/test_source_replacements.py 覆盖合成 HTML 解析、合法链接、缺失字数、畸形字段、gzip/deflate、响应大小限制及限流/重试。原有流水线、冷却、缓存、发布隔离回归继续适用。

# 前端检查

前端是三个静态页面，共用 `js/config.js`、`js/utils.js`、`js/nav.js`。无需前端构建工具；通过 HTTP 预览，不能直接双击 HTML 读取 JSON。

## 快速验证

```text
node --test tests/frontend_quality.test.cjs
python scripts/check_config_sync.py
python -m unittest discover -s tests -q
python scripts/serve_preview.py 8000
```

无真实数据时可使用 `python scripts/build_release.py --demo` 和 `python scripts/serve_preview.py 8000 --root dist`。页面采用相对资源路径，发布目录由 `scripts/build_release.py` 生成。

## 浏览器检查清单

| 范围 | 操作与预期 |
| --- | --- |
| 页面入口 | 3 个平台、9 个榜单分别打开榜单/风向标/创作灵感，共 27 个组合；标题、分类、日期对应当前榜单 |
| 小屏布局 | 320、390、768 像素宽度检查；平台与页面入口在第一行，榜单在第二行可横向滚动；选中榜单可见，主内容不横向溢出 |
| 手机分类菜单 | 打开、选择分类、关闭按钮、遮罩、Escape；关闭后隐藏分类不进入 Tab 顺序，焦点返回菜单按钮 |
| 搜索与筛选 | 搜索已知书名/作者、无结果、清空、Top 10、按指标/书名排序；分类切换后仍正常 |
| 日期 | 最新、上一快照日、下一快照日；日历最大日期以已构建最新快照为准；历史缺失时明确提示并恢复已加载日期、书籍、摘要和导出数据 |
| 风向标 | 切换分类与 7/14/30/全部周期；仅一天或没有趋势文件时显示空态并结束加载 |
| 创作灵感 | 切换周期、竞品/建议/内容特征分类，空内容有提示 |
| 设置 | 弹窗打开后焦点进入弹窗，Tab 循环，Escape 关闭并恢复焦点；浏览器不保存 API Key |
| 导出 | CSV/JSON/Excel 文件可生成，数据与当前页面一致；Excel CDN 不可用时 CSV/JSON 仍可使用 |
| 异常参数 | 未知 `rank`、`__proto__`、`constructor` 等回退默认榜单，不报 JavaScript 异常；旧 `female_new` 等参数继续兼容 |

Excel 依赖带 SRI 校验的 SheetJS CDN；页面书籍封面来自上游图片地址。离线单元测试不代表外部资源在所有网络都可用，浏览器检查应同时观察控制台与实际页面。

风向标初次只加载最近 7 个有效观察日；切换到 14/30/全部时补取缺少的日期，已请求日期复用缓存，每批最多 6 个请求。缺失或日期不匹配的趋势文件跳过，再向更早历史补齐观察日。

修改前端后要刷新页面。本地预览会重新验证资源缓存；已有 `dist/releases/` 是独立副本，需要重新构建发布包才能包含最新修改。

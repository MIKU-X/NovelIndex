# 发布目录与 Windows 定时任务

本轮处理执行入口和发布准备，不修补旧数据。已识别的历史移植部分现已完成替代，范围和源码发布边界见[来源核对](来源核对.md)。

## 不爬取、不配置 AI，先运行示例

在项目根目录执行（Python 3.10+，此步骤只需要标准库）：

```powershell
python scripts/build_release.py --demo
python scripts/serve_preview.py 8000 --root dist
```

打开 http://127.0.0.1:8000/ 。Windows 若没有 `python` 命令，改用已安装 Python 的绝对路径或 `.venv\Scripts\python.exe`。

示例从 `examples/demo_seed.json` 生成：9 个榜单、2026-01-01 至 2026-01-03 三天快照，全部作品、作者、简介和指标均为合成数据。按正常完整性门槛生成，并使用实际构建函数生成趋势、分类 API 与作者分析。不会访问小说网站，也不会调用 AI。AI 创作建议显示未配置状态；规则分析可用。

页面顶部显示演示横幅，JSON 带 `demo` / `data_notice`，书名以“演示·”开头，下载文件名带“演示数据”。固定的示例日期不触发真实采集失败告警。示例没有封面，不使用真实作品内容。

SheetJS 仍通过官方 CDN 加载固定的 0.20.0 版本和 SRI：断网时页面、趋势、JSON/CSV 可用；Excel 导出需要 CDN 可达。此次获取官方包返回 HTTP 403，未改用来历不明的镜像，也未声称 Excel 已通过离线验证。

## 独立发布目录

```text
dist/
  current.json
  releases/
    <时间-唯一编号>/
      index.html / author.html / trend.html
      css/ / js/
      data/ / api/
      LICENSE.txt / NOTICE.txt
      site-info.json / release-manifest.json
```

每次构建生成全新目录；验证通过才原子替换 `current.json`。构建失败保留旧指针和旧目录。Windows 发布文件继承发布父目录权限，不沿用私有临时目录权限。清单记录每个公开文件的 SHA-256。生成的 `dist/` 已被 Git 忽略。

预览器启动时解析一次 `current.json`，固定服务一个版本；新版本生成后重启预览器切换。上线时只把对应的 `dist/releases/<编号>/` 作为静态站点根目录或上传为托管平台的完整部署单元；不要把项目根目录或整个 `dist/` 作为网站根目录。

已有真实构建结果可打包：

```powershell
python scripts/build_release.py --source .
```

打包只读取公开 API 索引、日期索引所引用的文件及规定的分析文件。不会修改源 `data/` / `api/`，也不会重新爬取。检查各榜单索引、日期及引用一致性；不重新评判旧快照的完整性。若现有索引断链，命令会明确失败并保留原发布版本。

`.env`、密钥配置、爬虫源码、日志、SQLite、任务状态、参考项目和未被索引引用的任意 JSON 均不进入发布目录。真实榜单文字本身不会自动脱敏；需要确认内容使用范围后再选择真实数据公开。

## 配置计划任务

先用将要执行任务的 Windows 账户安装 Python 3.10+、项目依赖和浏览器：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m playwright install chromium
.\.venv\Scripts\python.exe -m patchright install chromium
```

起点使用真实 Chrome 时，该账户还需能启动本机 Chrome。依赖安装在所选解释器内；不要依赖开发终端临时设置的 PYTHONPATH。

双击 `setup.bat`，选择 `[7]` 进入新的 PowerShell 菜单。每天/每周可选时间、星期、运行模式；“立即触发”现在会调用真正已注册的任务，便于确认计划任务环境。每日和每周任务独立保留，切换周期后可在菜单删除不再需要的旧任务。

也可以在 PowerShell 中直接注册：

```powershell
# 默认优先 .venv\Scripts\python.exe，再找 PATH 中的 python.exe
.\scripts\register_task.ps1 -Schedule Daily -At '08:00'
.\scripts\register_task.ps1 -Schedule Weekly -Days Monday,Wednesday,Friday -At '18:00'

# 仅查看命令，不注册或修改系统任务
.\scripts\register_task.ps1 -Schedule Daily -At '08:00' -PrintOnly
```

任务沿用 `FanqieZhiShu_Daily` / `FanqieZhiShu_Weekly` 名称；同名注册会更新任务。动作分别保存绝对 `pythonw.exe` 路径、带引号的绝对脚本参数、绝对工作目录。任务不依赖 `cd && setup.bat`、启动目录或登录终端的 PATH。

默认模式使用 `Interactive`：用户已登录时，无需打开终端，锁屏后仍可后台执行；用户注销后不会执行。若需要注销后执行，使用本机凭据输入窗口：

```powershell
$taskCredential = Get-Credential
.\scripts\register_task.ps1 -Schedule Daily -At '08:00' -Credential $taskCredential
Remove-Variable taskCredential
```

此模式使用 Windows `Password` 登录类型，密码交给任务计划程序，不写入项目文件和任务命令。需要账户密码，不能用 Windows Hello PIN；账户须具有对应目录、浏览器和批处理登录权限。不要在聊天、`.env` 或命令参数中粘贴明文密码。注册提示拒绝访问时，在有权限管理该用户任务的 PowerShell 中执行。

没有使用 S4U 模式：微软文档说明该模式无法访问网络或加密文件，不适合这里的联网任务。[Microsoft 登录类型说明](https://learn.microsoft.com/en-us/windows/win32/taskschd/principal-logontype)。未指定工作目录时任务默认从 System32 启动，因此这里明确设置工作目录。[Microsoft 动作说明](https://learn.microsoft.com/en-us/powershell/module/scheduledtasks/new-scheduledtaskaction)。

任务设置为忽略同一任务的重复启动、错过后补跑、电池供电也允许运行，最长 12 小时；流水线自身仍使用进程锁。机器需开机且联网，不会自动唤醒或自动登录 Windows。

## 验证与排障

```powershell
# 安全的入口检查：不执行真实爬取/构建
.\.venv\Scripts\python.exe scripts/scheduled_run.py --check

# 真正创建、启动并删除临时计划任务（也可加 -Credential）
.\scripts\test_scheduled_task.ps1 -PythonPath (Resolve-Path '.venv\Scripts\python.exe').Path

# 在本机输入 Windows 凭据，验证 Password 登录类型、Session 0 和联网
# 不需要注销当前用户；密码不会回传到聊天或写入文件
.\scripts\test_scheduled_task.ps1 -PythonPath (Resolve-Path '.venv\Scripts\python.exe').Path -PromptForCredential -CheckNetwork

# 查看实际生产任务执行结果
Get-ScheduledTaskInfo -TaskName 'FanqieZhiShu_Daily'
```

测试在 `.runtime/scheduler test 中文 & !/<唯一编号>/` 放置隔离的 `run_all.py` 替身，走相同计划任务动作和生产启动器，验证无标准输入、工作目录、UTF-8 stdout/stderr 和 `0` / `7` 退出码。只清理自己创建的临时任务，保留本地报告；不运行真实爬取或清理真实任务状态。

执行日志：`logs/scheduled/<时间_进程号>.log`，对应 `.json` 保存完成时间和退出码。`setup.bat /auto` 使用同一入口并原样返回退出码。日志可能含运行信息，只保存在本地，不进入静态发布目录。

2026-09-08 已在本机 Windows Task Scheduler 实测通过 Interactive 后台模式及含空格、中文、`&`、`!` 的项目路径；没有使用真实账户密码或注销用户，因此 Password 模式与实际整轮采集在注销环境下的运行尚未验收。

## 首次 GitHub 开源的源码包

```text
python scripts/build_source_release.py
```

输出位于 `dist/source_releases/<编号>/`：包含 `NovelIndex/` 源码目录、`NovelIndex-source.zip` 与 `SHA256SUMS.txt`。目录内 `source-manifest.json` 记录每个文件的 SHA-256。包内 README 为面向使用者的说明，保留安装、示例、贡献、许可与来源链接；排除旧审查归档和真实网站截图。

使用该 `NovelIndex/` 目录建立首次公开仓库；旧工作区的 `.git` 历史不包含在包内，原仓库也未被删除或改写。当前替代实现不等于替代前历史代码已取得授权。发布前可在包中执行同样的 unittest、配置同步和示例构建命令。
